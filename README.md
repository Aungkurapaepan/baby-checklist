# ลิสต์ของใช้ลูกน้อย

เว็บเช็คลิสต์ของใช้เด็กแรกเกิดสำหรับใช้ร่วมกันหลายคน ติ๊กของที่ซื้อแล้ว เปรียบเทียบราคาหลายร้าน และดูประวัติย้อนหลังได้ ข้อมูลทั้งหมดเก็บใน Google Sheet ของคุณเอง

รายการเริ่มต้น 102 รายการ อ้างอิงจาก [Newborn Checklist ของ The Little Store](https://thelittlestore.co/th/pages/newborn-checklist)

## ทำอะไรได้บ้าง

- ติ๊กของที่ซื้อแล้ว ทุกคนที่เปิดเว็บจะเห็นตรงกัน (รีเฟรชเองทุก 15 วินาที)
- ใส่ราคาได้หลายร้านต่อหนึ่งรายการ เรียงจากถูกไปแพง และบอกว่าแพงกว่าร้านถูกสุดเท่าไร
- แก้ราคาได้ (ปุ่ม ✎) ถ้าใส่ราคาใหม่ด้วยชื่อร้านเดิม ราคาเก่าจะเก็บไว้ใน "ราคาที่บันทึกก่อนหน้า"
- กด "ซื้อที่นี่" เพื่อติ๊กพร้อมบันทึกราคาที่จ่ายจริง
- แท็บ "ประวัติ" บอกว่าใครทำอะไร วันไหน เวลาไหน
- เพิ่ม/แก้/ลบรายการ ใส่จำนวนและโน้ตได้

## ติดตั้ง (ครั้งเดียว ประมาณ 10 นาที)

### 1. สร้าง Google Sheet และใส่โค้ด

1. ไปที่ [sheets.new](https://sheets.new) สร้าง Google Sheet ใหม่ ตั้งชื่ออะไรก็ได้ เช่น "ลิสต์ลูกน้อย"
2. เมนู **Extensions → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้ววางโค้ดจากไฟล์ [`Code.gs`](Code.gs) ใน repo นี้
4. กดไอคอนบันทึก (💾)

### 2. สร้างแท็บและรายการเริ่มต้น

1. ในแถบด้านบน เลือกฟังก์ชัน **setup** แล้วกด **Run**
2. ครั้งแรก Google จะขอสิทธิ์ ให้กด **Review permissions** → เลือกบัญชี → **Advanced** → **Go to (ชื่อโปรเจกต์)** → **Allow**
3. กลับไปดู Sheet จะมีแท็บ `items` (102 รายการ), `prices`, `log`

### 3. เปิดให้เว็บเรียกใช้ได้

1. กด **Deploy → New deployment**
2. กดรูปเฟือง เลือก **Web app**
3. ตั้งค่า:
   - Execute as: **Me**
   - Who has access: **Anyone**
4. กด **Deploy** แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

### 4. ใส่ลิงก์ในเว็บ

1. เปิดไฟล์ [`config.js`](config.js) ใน GitHub แล้วกดรูปดินสอ (Edit)
2. วางลิงก์ระหว่างเครื่องหมายคำพูด เช่น

   ```js
   window.SHEET_API_URL = "https://script.google.com/macros/s/XXXXXXXX/exec";
   ```

3. กด **Commit changes**
4. รอประมาณ 1 นาที แล้วเปิดเว็บ GitHub Pages ของ repo นี้

## ข้อควรรู้

- **ใครมีลิงก์เว็บก็แก้ลิสต์ได้** ไม่มีระบบล็อกอิน ส่งลิงก์ให้เฉพาะคนที่ไว้ใจ ถ้าต้องการ ดูข้อมูลทั้งหมดและแก้ย้อนหลังได้ใน Google Sheet
- ชื่อที่ขึ้นในประวัติ คือชื่อที่แต่ละคนพิมพ์ตอนเปิดเว็บครั้งแรก (เปลี่ยนได้ที่ปุ่ม "เปลี่ยนชื่อ")
- ถ้าแก้โค้ดใน Apps Script ภายหลัง ต้อง **Deploy → Manage deployments → แก้ไข → Version: New version** ลิงก์จะยังเหมือนเดิม
- อย่าเปลี่ยนชื่อแท็บหรือหัวคอลัมน์ใน Sheet
